# Mini Proyecto Android - Login + Catálogo

Este es un proyecto práctico desarrollado por un grupo 
de estudiantes para reforzar el uso de **Git**, 
**GitHub**, **Jetpack Compose**, 
y **ViewModel** en el desarrollo de 
aplicaciones Android.

---

## Características del proyecto

- **Pantalla de Login**:
    - Validación de campos (email y contraseña).
    - Botón de ingreso habilitado solo cuando los campos son válidos.
    - No utiliza almacenamiento ni autenticación real.

- **Pantalla Home (Catálogo)**:
    - Lista de productos ficticios mostrados en un `LazyColumn`.
    - Cada producto tiene:
        - Imagen ilustrativa.
        - Título.
        - Descripción corta.
        - Botón "Ver más".

---

## Tecnologías usadas

- **Lenguaje**: Kotlin
- **UI**: Jetpack Compose
- **Arquitectura**: MVVM (Model-View-ViewModel)
- **Navegación**: Navigation Compose
- **Control de versiones**: Git y GitHub
